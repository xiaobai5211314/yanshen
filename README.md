# 纯净盐神 (YanShen Pure)

> 📖 **知乎盐选小说纯净阅读器与离线归档站**  
> 彻底剥离全网搬运站泛滥的弹窗、全屏穿透广告与推广骚扰，还原微信读书般的沉浸式阅读体验。

---

## 🌟 核心特性

- 🚫 **100% 零广告·零弹窗·零追踪**：彻底告别第三方搬运站令人头痛的遮挡式广告、全屏跳转与诱导点击，回归纯粹阅读。
- 📚 **全量 8,300+ 篇专栏小说即搜即看**：收录包含《黑镜规则怪谈》、《脑洞故事盒》、《白夜暗涌》、《江湖庙堂与市井》等 180+ 个热门知乎盐选专栏与高赞回答。
- ⚡ **离线秒开 & 智能持久化**：
  - 内置 35+ 篇口碑极高、当下最火的高赞精选小说全文，无需网络双击即可畅读。
  - 支持按需即时智能在线阅读与自动清洗，阅读过的内容自动缓存在本地浏览器的 `IndexedDB` 中，永久离线保存。
- 🎨 **微信读书级排版体验**：
  - **4 款经典护眼主题**：羊皮纸暖黄（Warm Paper）、极夜黑（Dark Night OLED）、极简纯白（Clean White）、浅草绿（Eye-care Green）。
  - **自由版式调节**：字号缩放（14px - 24px）、字体切换（现代黑体、文雅宋体、经典楷体）。
  - **阅读进度自动记忆**：精准记录每篇小说的滚动阅读百分比，下次打开自动续读。
- 🔖 **书签与历史管理**：支持一键加入书签、浏览历史记录管理、一键复制全文、生成分享直达链接。
- 📱 **全平台响应式适配**：支持手机端平滑抽屉导航与桌面端宽屏舒适双栏排版。

## 🛠️ 工程与目录结构

```text
盐神/
├── AGENTS.md                  # 子项目规则源（符合工作区规范）
├── README.md                  # 项目说明文档
├── index.html                 # 纯净阅读器单页应用 (SPA)
├── CNAME                      # 域名绑定配置文件
├── icon.svg                   # 高清矢量品牌 Logo
├── css/
│   └── style.css              # 现代化阅读器样式表 (4套色彩系统与排版)
├── js/
│   └── app.js                 # 核心阅读交互引擎、IndexedDB 缓存与路由
├── data/
│   ├── index.json             # 全站 8,300+ 篇专栏检索索引库
│   └── presets.json           # 预置离线高赞精选小说全文库
└── tools/
    ├── fetch_index.py         # 全量索引更新抓取脚本
    ├── sync_articles.py       # 离线爆款小说批量抓取与预置脚本
    └── deploy_server.py       # 云端服务器一键自动化部署脚本
```
